# [프로그래머스] 완주하지 못한 선수

## 1. 문제를 보고 처음에 떠올린 아이디어

마라톤을 참가한 선수에서 마라톤을 완주한 선수를 빼면 마라톤에 완주하지 못한 선수가 나온다.

참가선수 배열(participant)에서 완주선수 배열(completion)을 빼려면 뭔가 함수? 가 필요하다고 생각해서 검색했다.

removeAll() 메소드를 발견했다.

이 메소드를 사용하는 방밥은 2가지가 있었는데
첫번째는 배열을 리스트로 만들어서 서로 빼는 것이다.
두번째는 배열을 해시에 넣어 리스트로 변환 후 함수를 사용하는 것이다.

둘다 사용가능하지만 문제에서 중복된 선수는 한명만 출력하라고 되어있기 때문에 내부적으로 중복을 허용하지 않는 Hash를 사용하기로 했다.
